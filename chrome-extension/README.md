# Note Chrome Extension v1.3

## 快捷键
- `Ctrl+Shift+Y`：摘录当前选中文字
- `Ctrl+Shift+S`：框选网页截图

快捷键由页面内容脚本直接监听，不再依赖 Chrome 是否成功分配扩展命令。更新插件后，已打开的旧网页建议刷新一次。

## 受限网站
插件弹窗新增“兼容选文”。遇到禁止右键、禁止复制或 CSS 禁止选中的网站时，对当前网站开启即可；设置会按域名记住。

兼容选文会恢复常见 DOM 文本的选择和右键行为。若网页把正文绘制在 canvas/图片中，或使用无法访问的 closed Shadow DOM，则不存在可直接读取的文字节点，请改用“框选截图”。

## 其他
- 继续记住上一次成功写入的笔记。
- 网页文字/截图来源样式与本地图书一致。
- 默认连接 `http://127.0.0.1:3030`。
