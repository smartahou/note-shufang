# v1.10.2 Atomic capture Backspace

- In Rich mode, a book/web text excerpt is treated as one atomic capture when Backspace is pressed from the following block.
- PDF/web screenshot capture figures use the same behavior.
- Backspace removes the complete capture instead of moving the caret into capture content/source metadata.
- Ordinary user-created blockquotes keep their existing editing behavior.
- No database/schema changes.
