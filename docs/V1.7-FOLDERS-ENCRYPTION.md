# v1.7 目录与加密上锁

- 目录：固定根目录 + 一层用户子目录，目录数据保存在 `data/folders.json`，笔记通过 `folderId` 关联。
- 加密：scrypt(N=32768,r=8,p=1) + AES-256-GCM。
- 加密范围：标题、编辑类型、正文、摘要、Note 本地图片附件。
- 明文保留的必要元数据：note id、folderId、locked 标记、创建/更新时间、加密算法参数与密文。
- 临时解锁密钥只驻留 Note 进程内存，浏览器仅保存随机 unlock token；重启进程后全部失效。
- 锁定状态下普通 GET 不返回密文或正文，只返回匿名化元数据。
- 锁定笔记的保存、删除、解除加密都需要有效 unlock token。
- 书房目标笔记列表隐藏已锁笔记，避免跨应用绕过密码直接写入。

- 加锁笔记在未解锁状态下不能被移动目录；目录移动同样由服务端校验 unlock token。
- 已解锁加密笔记新增本地图片时使用内存上传，图片直接写入 AES-GCM 加密载荷，不先落到 `uploads/` 明文文件。
- 加锁时会递归清理 Note 管理范围内的备份、隔离区、事务前驱和残留 JSON 临时文件中的同 note-id 明文记录。
- 启动时会检查失效的 `folderId`，把孤立笔记安全移回根目录，避免目录文件异常后笔记“消失”。
- 多窗口竞态：若另一窗口在本窗口尚有未保存修改时给笔记上锁，本地修改只暂存在当前页面内存；输入密码后再加密保存，不直接丢弃。
