# v1.4 实时同步与编辑器快捷键

- Note 新增 SSE 实时事件通道（浏览器原生 EventSource），无需额外依赖。
- 多个 Note 页面同时打开时，新增、修改、删除会自动刷新列表；当前笔记在本地无未保存输入时会自动刷新正文。
- 书房把 PDF 截图追加到 Note 后，打开着的 Note 会立即收到事件并更新，无需手动刷新页面。
- 若截图到达时当前笔记正处于自动保存缓冲期，会把截图片段直接合并进当前编辑 DOM，再由 Note 正常保存，避免覆盖刚输入的内容。
- PDF 截图下方“书名 / 页码 / 截图类型”和“打开原书”来源栏设为 contenteditable=false，并对旧笔记运行时自动补只读属性。
- 新增快捷键：Ctrl+B 加粗、Ctrl+H 二级标题、Ctrl+/ 斜体、Ctrl+' 引用；再次执行即取消。macOS 同时支持 Command。
- Markdown / HTML 源码模式也支持上述快捷键，并做基本的成对标记/行前缀切换。
