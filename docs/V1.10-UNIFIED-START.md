# v1.10.0：统一启动与本地域名

## 统一启动

```bash
node start
```

首次指定或切换书库：

```bash
node start "G:\books"
```

启动器会同时管理 Note、书房与本地 HTTP 入口。书库路径会保存到 `~/.shufang/start.json`；若该文件不存在，会从既有 `library.db` 中选择最近扫描且仍有效的书库目录。

## Windows 本地域名

hosts 使用 ASCII Punycode：

```text
127.0.0.1 xn--uvz335a.com    # 笔记.com
127.0.0.1 xn--1jqt79b.com    # 书房.com
```

浏览器使用：

```text
http://笔记.com
http://书房.com
```

`node start` 在 `127.0.0.1:80` 根据 Host 转发：

- `笔记.com` → `127.0.0.1:3030`
- `书房.com` → `127.0.0.1:39271`

Note / 书房内部通信仍直接使用 localhost，不通过本地域名绕一圈。

## 已移除的书籍改名功能

- 删除 `书目校正` 独立工具与对应文档。
- 不再扫描 `rename-log-*.json`。
- 不再生成改名审查报告。
- 不再显示“改名复核”筛选或“待复核”标签。
- 旧 SQLite 中 `rename_*` 兼容字段/表不 DROP，避免为了删功能而做破坏性迁移。
