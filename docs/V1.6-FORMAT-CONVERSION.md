# v1.6 格式转换

Note 新增富文本 / HTML 与 Markdown 的显式转换。

## 为什么不自动转换

HTML 可包含 class、style、data-*、表格、复杂媒体以及书房业务元数据；纯 Markdown 无法完整表达这些结构。为避免切换编辑模式时静默破坏内容，本版不再跨 Markdown 边界自动转换。

## 规则

- 富文本 ↔ HTML：直接切换，底层均为 HTML。
- 富文本 / HTML → Markdown：点击“转为 Markdown”。常规语义标签转换为 Markdown；复杂/带样式/带业务属性的节点保留为 Markdown 中的原始 HTML 片段。
- Markdown → 富文本：点击“转为富文本”，使用现有 Markdown 渲染器生成 HTML。之后如需源码可再切换到 HTML。
- PDF/TXT/EPUB 的书房来源块与图片关联信息在转换中保留。
