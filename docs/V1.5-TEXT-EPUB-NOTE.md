# v1.5 · TXT / EPUB / Markdown 划线与摘录到 Note

- TXT、Markdown：选择文本后可“划线”或“摘到笔记”。
- EPUB：在章节正文选择文本后可“划线”或“摘到笔记”。
- 划线保存在 `~/.shufang/library.db` 的 `reader_annotations` 表中。
- 关联主键仍为书籍 SHA-256；TXT/MD 使用字符偏移，EPUB 使用章节索引/章节 entry + 字符偏移。
- 摘录写入 Note 时，正文可继续编辑，底部来源栏只读。
- PDF 截图、TXT/MD/EPUB 摘录统一使用 `.note-book-source` 来源栏。
- HTML/PDF 导出保留来源栏和原书链接。
- 从 Note 点击“打开原书”会回到对应页/章节/文本位置。

数据库 schema 从 42 升到 43。升级前继续使用 `VACUUM INTO` 创建冷备份。
