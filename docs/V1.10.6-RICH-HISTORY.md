# v1.10.6 - Unified rich-text history

- Rich mode now has one application-owned undo/redo manager.
- Snapshots include cleaned HTML, selection bookmark and editor scroll position.
- Typing is coalesced; structural capture deletion commits immediately as one transaction.
- Ctrl+Z / Ctrl+Y, toolbar undo/redo and beforeinput historyUndo/historyRedo all route to the same manager.
- External capture append is adopted as synchronization baseline instead of a local undo entry.
- PDF capture picker now restores the same last successful Note target used by TXT/EPUB excerpts.
- No database schema migration.
