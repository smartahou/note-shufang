# v1.9.2 Chrome 网页摘录修复

- 摘录弹窗两处滚动条改为细滚动条，隐藏上下箭头，降低视觉干扰。
- “写入笔记”按钮改为与 Note 暗色界面一致的紧凑样式。
- 修复文字摘录快捷键：不再依赖 Chrome `commands` 是否成功注册，改由 `document_start` 内容脚本直接监听：
  - `Ctrl+Shift+Y`：文字摘录
  - `Ctrl+Shift+S`：框选截图
- 内容脚本缓存最近一次网页选择文本，页面拦截复制时仍可直接读取选择内容。
- 新增“兼容选文”开关（按域名记忆）：
  - 强制恢复 `user-select: text`
  - 尽量阻止网页脚本拦截 `selectstart / contextmenu / copy`
  - 对 open Shadow DOM 同步注入选文样式
- 兼容模式主要面向微信读书一类禁止右键/复制/选中的 DOM 网页。
- 若正文是 canvas、图片、视频画面或 closed Shadow DOM，浏览器本身没有可读文字节点，仍应使用框选截图摘录。
