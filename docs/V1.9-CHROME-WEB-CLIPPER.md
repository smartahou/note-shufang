# v1.9 Chrome 网页摘录

Chrome 扩展位于工程 `chrome-extension/`。运行 `node note` 后，在 `chrome://extensions/` 开启开发者模式并加载该目录。

支持选中文字摘录、框选截图、已有/新建笔记选择、目录选择、网页标题与 URL 来源关联。来源块复用 Note 现有 `.note-book-source` 风格，因此 PDF / TXT / EPUB / 网页来源视觉一致；导出时来源按钮自动移除。

插件不直接访问磁盘数据文件，只调用 `127.0.0.1` 上的 Note API。上锁笔记不会出现在插件目标列表中，服务端也会再次拒绝锁定状态下的写入。
