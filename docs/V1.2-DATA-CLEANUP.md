# v1.2 数据清理与防复发

第一次启动时：

1. 复制当前 `data/notes.json` 到 `quarantine/cleanup-v1.2-*/notes-before-cleanup.json`。
2. 清理所有 `（恢复副本）` / `(恢复副本)` 标题记录。
3. 同 ID 冲突只保留更新时间最新的一条。
4. 标题、类型、正文完全一致的重复记录只保留一条。
5. 旧 `backups/` 文件全部移入本次 quarantine，活动 backups 目录重新变为空目录。
6. 旧 `recovery-report.json` 移入 quarantine。
7. 写入 `.cleanup-v1.2.json` 作为执行报告。

之后每次启动：

- 不扫描 backups；
- 不扫描旧工程或相邻目录；
- 不做历史合并；
- 只对当前数据库做明确的脏数据自检。

`quarantine/` 是永久非活动区，程序不会自动读取或恢复其中任何文件。
