# v1.8 PDF 连续阅读修复

1. **截图页码误判**：当前页使用阅读锚点命中页判断；锚点落在第 X 页正文内时，截图固定使用 X 页。
2. **滚动条无限增长**：连续模式最多保留约 6 个 PDF 页面节点；追加新页时回收远端旧页。
3. **追加页跳动**：不再由图片 `onload` 递归追加；每次向下滚动接近底部只追加一页。回收旧页时按真实 DOM 高度补偿 `scrollTop`。
4. **浏览器锚点干扰**：PDF 容器关闭 `overflow-anchor`，避免浏览器与程序同时补偿导致双重跳动。
5. **异步图片高度变化**：若已加载页面位于视口上方，图片实际高度与占位高度不一致时补偿差值。

此版本不修改 Note 数据、书房数据库 schema、阅读进度格式或 PDF→Note 来源数据格式。
